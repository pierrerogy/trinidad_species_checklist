# Aquatic invertebrates of epiphytic tank bromeliads on the island of Trinidad, W.I.: an illustrated checklist
This project aimed to document the diversity of invertebrates in epiphytic tank bromeliads on the island of Trinidad, Trinidad and Tobago, West Indies. The present repository contains the cleaning pipeline from the raw data to the clean data that is present in the following publications.
